# calculator

A little toy calculator package.



## `git bisect`

The first commit of this repository was `a41d7d27bcc109ee1ba363f6c552f8643b313204`

So you can run :

    git bisect start
    git bisect bad
    git bisect good a41d7d27bcc109ee1ba363f6c552f8643b313204

Now you're golden.

Or you can run this which will show you the same thing, by running the script:

    git bisect run run.py
